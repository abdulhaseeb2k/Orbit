# Language policy: English everywhere

Everything in this repository is written in **English** — no exceptions:

- Source code: identifiers, comments, KDoc, log messages.
- All user-facing UI text in both apps (Android and desktop).
- All documentation: README, COMMANDS, release notes, design docs.
- Commit messages, tags, and GitHub release descriptions.

If any Roman-Urdu (or other non-English) text is found in code or docs,
translate it to English as part of the change being made.

Conversation with the project owner may be in any language — this rule is
about the repository's contents only.
